# MY JAPAN RAILWAY 150th ・ 駅スタンプ

从 **https://railway150.jp/contents/stamp/**（JR 集团 TRAIN TRIP 网页应用）逆向整理出的
全国车站数字印章原图 + 站名索引 + 可交互画廊。

![logo](assets/logo.svg)

---

## 1. 逆向结论：资源规律

站点是 Nuxt 3 SPA，但所有印章图都是 **S3 上的公开静态文件**，无需登录、无签名、无 Referer 校验：

```
https://railway150.jp/contents/stamp/assets/img/stamp/{ID}--0{n}.png
```

| 项目 | 说明 |
|---|---|
| `ID` | **1000 – 2234**，连续无缺口，共 **1235** 个 |
| `n` | 墨色档位 **1–6**，由盖印时按压的时长决定，`06` 最浓 |
| 尺寸 | 640 × 640 PNG，调色板 + 透明；服务器只提供这一种分辨率，**没有矢量源文件** |
| 缩略图 | `assets/img/stamp_thum/{ID}--0{n}.png` |
| 地图针 | `assets/img/stamp_pin/{ID}.png` |
| 分享图 | `assets/img/sharer/ogp_{ID}.png` |

站名 / 地址 / 经纬度等元数据**没有静态表**，只由 `/system/api/**` 在登录后按用户返回，
所以本包的站名是**识图得到的最佳努力结果**，非官方数据。

## 2. 站名是怎么来的

```
① 下载 1235 张 --06 原图
② Apple Vision OCR 打底
③ 拼联络表：16 格 / 张 → 78 张
④ 视觉大模型逐格读图 → TSV（CC GOAT / DeepSeek V4.1 Flash）
⑤ 人工查看剩余无法识别的 22 张 → 判定为「駅そば」系列
```

覆盖率 **1235 / 1235**。其中 115 张是「駅そば」站内荞麦系列、1 张是 TRAIN TRIP 标志，
图案本身不含站名。同一车站有**多张不同图案**的印章，所以站名重复是正常的。

## 4. 画廊功能

> 当前版本 **1.0.0** ・ 2026-10-05

**四个标签页**

| 标签 | 内容 |
|---|---|
| 全部 | 1235 枚全量，支持搜索、地区筛选与「随机一枚」 |
| 我的 | 已盖过的章，按你的**实际墨色与歪斜角度**呈现 |
| 统计 | 收集进度、**各地区完成度**、最近盖章 |
| 关于 | 版本号、图片来源、站名来源、收集记录、版权说明 |

**地区筛选**：全部页搜索框下方有一排地区胶囊，按 JR 六家公司划分
—— 北海道 / 东日本 / 东海 / 西日本 / 四国 / 九州，外加「其他」。

地区数据来源：粉丝站名表里标注的 JR 公司 926 条 + Wikidata 都道府县 102 条 + 人工判定 15 条。

| 地区 | 枚数 |
|---|---|
| 东日本 | 312 |
| 西日本 | 269 |
| 九州 | 170 |
| 东海 | 166 |
| 北海道 | 97 |
| 四国 | 95 |
| 其他 | 126 |

「其他」主要是 115 张「駅そば」站内荞麦系列——图案里没有站名，无法定位到具体车站。

**顶部进度条**实时显示 `已收集 N / 1235`，已收集的卡片右上角有蓝点。

**搜索**同时支持编号 / 日文 / 简体 / 罗马字：

| 输入 | 命中 |
|---|---|
| `1666` | 軽井沢駅 |
| `軽井沢` / `轻井泽` / `輕井澤` | 軽井沢駅 |
| `KARUIZAWA` / `karui` | 軽井沢駅 |
| `东室兰` | 東室蘭駅 |

**押印**复刻原版交互：点开卡片 → 空白纸框 → 长按时落点浮出虚线方框并淡入飞鸟暗纹 →
松手后印章落在落点上，带随机歪斜。墨色与歪斜会存进 localStorage，
所以每个站都是「你自己盖的那一枚」。

盖完之后印章下方有一条 **6 格墨量刻度条**，可以直接拖动改变深浅，
印章会实时换成对应档位的原图并更新记录。刻度条用黑白灰阶的墨量梯度表示浓淡。

印章右下角两个图标按钮：

| 图标 | 作用 |
|---|---|
| ↻ | 重新盖，清空重来 |
| ↗ | 在同标签页打开该档位的原图链接 |

原图链接会跟着墨色档位变，例如 4 档时打开的是 `{ID}--04.png`。

| 按压时长 | 档位 |
|---|---|
| ≤ 200 ms | 01 |
| ≤ 400 ms | 02 |
| ≤ 600 ms | 03 |
| ≤ 800 ms | 04 |
| ≤ 1000 ms | 05 |
| > 1000 ms | 06 |

## 5. 两种图片来源

页面靠 URL 参数在两种模式间切换：

| 模式 | 地址 | 图片来源 | 用途 |
|---|---|---|---|
| **链接模式** | 直接打开 | railway150.jp 官网 | 默认，线上部署用 |
| 本地模式 | 加 `?local=1` | 本机 `stamps/` `thumbs/` | 离线预览 |

线上仓库**只包含页面本身**，不托管任何印章图：

```
index.html
assets/
data/
README.md
```

合计约 740 KB。`stamps/` `thumbs/` `samples/` `tools/` 共约 900 MB 保留在本地，不上传。

这样做的好处是仓库极小、不涉及图片的再分发；代价是**页面依赖 railway150.jp 的素材一直在线**。
活动结束后若官网素材下线，本地那份完整备份可以用 `?local=1` 继续跑。
