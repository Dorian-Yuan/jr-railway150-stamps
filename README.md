## 怎么玩

### 一 · 逛

「全部」页一次铺开 1235 枚，往下滑自动加载。不知道看什么就点「随机一枚」。

### 二 · 找

搜索框同时认得四种写法：

| 你输入 | 会找到 |
|---|---|
| `1666` | 軽井沢駅 |
| `軽井沢` | 軽井沢駅 |
| `轻井泽` | 軽井沢駅 |
| `KARUIZAWA` | 軽井沢駅 |

也可以点地区胶囊，只看北海道、东日本、东海、西日本、四国、九州其中之一。

### 三 · 盖

点开任意一枚，纸框是空的——**按住不放**，落点会浮出虚线方框；松手，印章就盖上去。

按多久决定墨的浓淡：不到 0.2 秒最淡，超过 1 秒最浓。同一个站，每次盖出来的深浅和歪斜角度都不一样，是你自己那一枚。

盖完还可以拖下面那条 **6 格墨量刻度条**，随时改深浅。

### 四 · 收

盖过的章都在「我的」里，可以按地区筛选。「统计」页看总进度和各地区完成度。顶部进度条随时显示已收集多少枚。

### 五 · 附近

「附近」页用定位找出离你最近的 **16 个车站**，附直线距离。出门时挑顺路的那几个正好。

## 你的数据

盖过的章、墨色深浅、定位结果，**都只存在这台设备的浏览器里**，不会上传到任何地方。换设备或清空浏览器数据，收集记录就没了。
